# 柔道整復師 学習ポータル｜納品説明書

作成者：教員個人制作（学校公式サイトではありません）  
公開日：2026年9月23日頃  
用途：国家試験対策・授業復習の補助教材

---

## 1. ひとことで言うと

解剖学・生理学・一般臨床医学の**国家試験過去問を、ブラウザで解ける無料の学習サイト**です。  
ログイン不要。スマートフォンでも使えます。

**公開URL**  
https://nekomarugt.github.io/j-kokushi-portal/

**ソース（GitHub）**  
https://github.com/nekomarugt/j-kokushi-portal

---

## 3. 主な機能（現場で説明しやすい点）

- 回数指定・ランダム出題・出題数の選択
- 解答後の正誤表示と解説
- **今回間違えた問題だけ**の再挑戦
- **苦手問題だけ復習**（端末内の学習記録に基づく）
- 一般臨床では総論／各論の切り分け、所見からの逆引き
- 学習記録は各端末のブラウザ内（`localStorage`）のみ。**サーバーに学生個人情報は保存しない**

---

## 4. 技術・運用（事務・情シス向け）

- 静的サイト（HTML / CSS / JavaScript / JSON）
- ホスティング：GitHub Pages（HTTPS）
- 学生アカウント・パスワード・学籍番号の収集なし
- 外部決済・広告なし（過去問部分）
- 改修はリポジトリを更新して再公開する運用

---

## 5. 教育上の位置づけ・免責

- 教員が授業・国試対策の補助として整備した個人制作物です。
- **学校の正式シラバスや公式LMSの代替ではありません。**
- 診療・臨床判断の根拠として用いるものではありません。
- 問題・解説データは作成者側で整備した学習用データです。公式の過去問冊子の電子版提供を意味しません。
