# note 公開手順（学習資料）

ポータル上の学習資料全文は非公開にし、note 有料記事へ誘導する運用です。  
下書きファイル：

- `physiology-guide-note.md` … 生理学
- `clinical-guide-note.md` … 一般臨床医学

## 手順

1. [note](https://note.com/) で新規記事を作成（アカウント：`tomo703`）
2. **有料設定**をオン（価格は下書きの「案」を参考に調整）
3. **無料部分**に、下書きの「無料部分（プレビュー）」を貼る
4. **有料本文**には、下書きの「有料部分の目次」を貼る  
   - **推奨デフォルト：** 本文は「目次＋使い方＋ポータル連携」まで  
   - **全文は PDF を note に添付**（長文・画像が多く、貼り付け制限や更新に強い）
5. 公開後、記事URLを控える
6. ポータルの CTA は当面 `https://note.com/tomo703`（プロフィール）。  
   **個別記事URLが用意できたら** Grok Bot に「physiology-guide / clinical-guide のリンクを記事URLに差し替えて」と依頼する

## なぜ全文を note にベタ貼りしないか
- note の記事容量・編集UI的に、画像付き長文は重い
- PDF添付／分割記事の方が更新しやすい
- ポータル側は CTA のみ残し、旧ブックマークでも 404 にしない

## PDFについて
まだPDFが無い場合は、アシスタントに「生理学／一般臨床の学習資料PDFを生成して」と頼めます。
