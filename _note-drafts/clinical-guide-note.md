## 有料部分の目次（本文に貼る）

### 使い方
1. ポータルの一般臨床医学過去問で弱点を把握  
2. 総論／該当疾患章のPDFで復習  
3. 「所見から逆引き」機能と往復して定着  

### ポータル連携
- 過去問（無料）：学習ポータルの「一般臨床医学」  
- 学習資料（本記事）：総論・各論

### 総論 詳細目次
- **診察概論と問診** … 診察の流れと問診の基本  
- **視診** … 姿勢・歩行・皮膚・顔貌・四肢  
- **打診** … 打診音と臓器の位置  
- **聴診** … 肺・腹部・心臓の聴診  
- **触診** … 皮膚・筋・腹部の触診  
- **生命徴候** … 体温・血圧・脈拍・呼吸  
- **感覚検査** … 表在感覚・深部感覚・複合感覚  
- **反射検査** … 表在反射・深部反射・病的反射  
- **代表的な臨床症状** … 出血傾向と髄膜刺激症状 など  

### 各論 詳細目次
- **循環器疾患** … 先天性心疾患・弁膜症・虚血性心疾患・心不全・血管疾患  
- **呼吸器疾患** … 肺感染症・喘息・COPD・肺腫瘍・気胸  
- **消化器疾患** … 腹痛・食道・胃十二指腸・腸疾患  
- **栄養・代謝疾患** … 糖・脂質・尿酸・ビタミン・骨代謝  
- **内分泌疾患** … 下垂体・甲状腺・副腎・尿崩症  
- **血液・造血器疾患** … 貧血・白血病・出血性素因・骨髄腫  
- **神経疾患** … 脳血管障害・変性疾患・脱髄・神経筋疾患  
- **腎・尿路疾患** … 腎障害・糸球体疾患・尿路感染・結石  
- **感染症・リウマチ系疾患** … 細菌・ウイルス・性感染症・自己免疫疾患
